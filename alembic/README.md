# Alembic migrations

This directory is the controlled schema-change entry point for InsightFlow.

Before creating the initial baseline migration:

1. Make a non-destructive inspection of the target PostgreSQL schema.
2. Compare the live schema with `Base.metadata`.
3. Decide whether the database needs a baseline stamp or incremental changes.
4. Review the generated migration manually.
5. Test upgrade and downgrade against a disposable database.

Do not run an autogenerated migration against a production database without
review. Do not drop or recreate an existing database to make a migration pass.

Typical commands:

```powershell
& ".\.venv\Scripts\python.exe" -m alembic current
& ".\.venv\Scripts\python.exe" -m alembic revision --autogenerate -m "describe change"
& ".\.venv\Scripts\python.exe" -m alembic upgrade head
& ".\.venv\Scripts\python.exe" -m alembic downgrade -1
```
